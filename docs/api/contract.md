# REST API v1

| Method | Route | Access / behavior |
| --- | --- | --- |
| GET | `/api/v1/runtime` | Public runtime identifier |
| POST | `/api/v1/auth/otp/send` | Authorized mobile → opaque challenge and delivery receipt |
| POST | `/api/v1/auth/otp/verify` | mobile/challengeId/otp → verified session; Java returns access JWT |
| POST | `/api/v1/auth/otp/resend` | mobile/challengeId; cooldown, expiry and delivery limits |
| POST | `/api/v1/auth/logout` | Review session revocation; Java client clears its in-memory token |
| GET | `/api/v1/auth/me` | Java OTP token principal; review verified OTP cookie session |
| POST | `/api/v1/auth/users` | ADMIN creates legacy user records; password login remains disabled |
| GET | `/api/v1/{collection}` | Published records with q/category/status/page/size/sort |
| GET | `/api/v1/{collection}/{slug}` | Published record or 404 |
| GET | `/api/v1/search?q=...` | Published project/technology/skill/experience/article/service results |
| POST | `/api/v1/contact` | Validated brief; idempotent submission key; no private lead response |
| POST | `/api/v1/analytics/events` | Consent=true; allowlisted event/resource |
| GET | `/api/v1/admin/{collection}` | ADMIN / EDITOR content reads |
| POST | `/api/v1/admin/{collection}` | ADMIN / EDITOR content creation, settings/profile restricted |
| PUT/PATCH | `/api/v1/admin/{collection}/{id}` | Complete update representation with current version |
| DELETE | `/api/v1/admin/{collection}/{id}` | ADMIN only |
| GET/PATCH | `/api/v1/admin/contact[/{id}]` | ADMIN CRM reads / status update with version |
| GET | `/api/v1/admin/analytics?days=30` | ADMIN aggregate counts; unique visitors unavailable |
| DELETE | `/api/v1/admin/analytics/expired` | ADMIN retention cleanup |
| GET/POST | `/api/v1/admin/media` | ADMIN / EDITOR upload/list |
| GET | `/api/v1/admin/media/{id}/download` | Authenticated file download |
| GET | `/api/v1/media/{id}/download` | Published reference required |

Collections: profile, projects, technologies, skills, experience, education, companies, services, articles, categories, resume, timeline, settings. Settings is not a public collection.

Page response:

```json
{"items":[],"total":0,"page":0,"size":24,"totalPages":0}
```

Common content: id, resource, name, slug, summary, category, status, published, featured, sortOrder, data, createdAt, updatedAt, version. Extended data is a JSON object containing project technologies/links/features or relevant CMS fields. It is public content, not a credentials store.

Errors return a safe message, with validation fields when supported. HTTP 400 validation, 401 authentication, 403 authorization/origin, 404 not found/unpublished, 409 duplicate/stale version, 429 rate limit, 503 review storage unavailable. Contact submission uses a client-generated submissionKey to prevent duplicate records after retry.

All public contact success receipts return only id/status. No email notification or provider SMS is sent by this endpoint. Those provider adapters require separately configured credentials and are not claimed as deployed.

Swagger/OpenAPI is generated by the Java service in development/staging. The review documentation page includes a real GET request inspector; it does not invent live examples.

OTP configuration is server-only: FAST2SMS_API_KEY, FAST2SMS_OTP_ID, ADMIN_ALLOWED_PHONES. Unknown numbers never trigger SMS requests. Public challenge receipts contain masked numbers, expiry and retry timing; they never contain a code or provider authorization. Review sessions are opaque HttpOnly cookies; admin identity headers cannot replace them. The old review `/auth/claim` endpoint returns 404.
